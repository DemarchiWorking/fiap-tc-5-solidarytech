Regras de segurança durante a validação

  • Nenhuma credencial em arquivo, print ou chat. Senhas saem só no seu terminal (./solidary senhas). A chave do Datadog vive no AWS Secrets Manager e não é digitada em nenhum passo deste caderno.
  • Passos marcados com faixa vermelha alteram o ambiente de propósito (falha simulada, restore). Execute exatamente como descrito; todos se desfazem sozinhos ou têm o passo de volta.
  • Não use o endereço *.eks.amazonaws.com no navegador: é a API do Kubernetes e responde 401 por projeto. A interface é pelo NLB.

F4-03

Restore comprovado em namespace isolado

Medido
Onde: TERMINALTempo: 5 minEvidência: 07-evidencias/dr-velero-backup-restore.txt
Duas travas obrigatórias, aprendidas em execução real (item 6 da evidência): (1) só restaure com todos os snapshots do backup em completed; (2) só apague PV cujo nome comece com velero-clone- e cujo claimRef esteja em dr-drill-restore. Nunca apague um PV pvc-…: esse é de produção.
  1. Escolha o backup e confirme os snapshots: 
    BK=$(kubectl -n velero get backups.velero.io --sort-by=.metadata.creationTimestamp -o jsonpath='{.items[-1:].metadata.name}'); echo $BK
aws ec2 describe-snapshots --owner-ids self --filters "Name=tag:velero.io/backup,Values=$BK" --query 'Snapshots[].[SnapshotId,State]' --output text   # todos "completed"?
  2. Restaure só o PVC do Prometheus num namespace isolado: 
    cat <<EOF | kubectl apply -f -
apiVersion: velero.io/v1
kind: Restore
metadata: { name: drill-$(date +%H%M%S), namespace: velero }
spec:
  backupName: $BK
  includedNamespaces: ["monitoring"]
  includedResources: ["persistentvolumeclaims","persistentvolumes"]
  labelSelector: { matchLabels: { app.kubernetes.io/name: prometheus } }
  namespaceMapping: { monitoring: dr-drill-restore }
  restorePVs: true
EOF
kubectl -n dr-drill-restore get pvc -w      # Ctrl+C em Bound
  3. Confira as travas e limpe só o que é do drill: 
    PV=$(kubectl -n dr-drill-restore get pvc -o jsonpath='{.items[0].spec.volumeName}'); echo $PV   # TEM de ser velero-clone-…
kubectl delete namespace dr-drill-restore
case "$PV" in velero-clone-*) kubectl delete pv "$PV" --ignore-not-found ;; *) echo "NAO APAGAR: $PV" ;; esac
Restore Completed; PVC Bound em ~12 s num PV velero-clone-… criado a partir do snapshot; depois da limpeza, namespace e PV do drill NotFound, sem custo órfão.
